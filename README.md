# Portfolio Morvan Lucky

Site estático premium com:
- efeito de virada de páginas;
- tradução por bandeirinhas: português, espanhol e inglês;
- WhatsApp Brasil e Espanha clicáveis;
- Instagram, LinkedIn e e-mail clicáveis;
- download do PDF completo;
- foto principal integrada ao fundo com desfoque.

## Como publicar no GitHub Pages

1. Entre no repositório: https://github.com/morvanluckychefe/Portfolio-Morvan-Lucky
2. Envie estes arquivos para a raiz do repositório:
   - index.html
   - style.css
   - script.js
   - portfolio-morvan-lucky.pdf
   - pasta assets
3. Vá em Settings > Pages.
4. Em Source, escolha: Deploy from a branch.
5. Em Branch, escolha: main e /root.
6. Clique em Save.

O link final deverá ficar parecido com:
https://morvanluckychefe.github.io/Portfolio-Morvan-Lucky/
